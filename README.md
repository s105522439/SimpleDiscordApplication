A WPF project that implements a simple instant online multi-person chat channel similar to Discord. Based on the MVVM design pattern, the CommunityToolkit.Mvvm toolkit is used for rapid development, and the project is optimized for multi-threading. The project includes a self-built server and client, using the Tcp protocol, and connecting and communicating between the client and the server through the TcpListener and TcpClient classes in the System.Net.Sockets namespace. The Task class is used for multi-thread management, and the client and server set up new threads separately to keep listening at all times. The PacketReader and PacketBuilder classes are established to encapsulate and decode the transmitted data in binary, and multiple operation codes (function codes) are set. The client and server obtain the operation code to parse and trigger the corresponding event. The event handler in ViewMoodel responds and decodes and processes the incoming data frames in turn to complete the corresponding functions.
